# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my skills, education, experience, resume, and contact information.

## 🚀 Features

* 🎨 Modern and clean UI
* 📱 Fully responsive design
* 💻 Desktop, tablet, and mobile support
* 🛠️ Skills and technologies section
* 🎓 Education and experience section
* 📄 Resume section
* 📩 Contact form
* ⚡ Smooth scrolling and interactive elements
* ✨ Modern animations and visual effects

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **EmailJS** – Contact form email integration

* 💻 Desktop

* 📟 Tablet

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/portfolio.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

No additional installation or dependencies are required.
